# Empirical extension Python deps.

# manifest-owned `.arpipeline/update_inputs/deps/` provisioning record inside
# each deployment.
#
# Before adding a dep, check where it writes caches/config by default (#212):
# a `~/.something` default outside the sandbox writable sets (Claude
# settings.json allowWrite, codex permissions in launch.sh, grok
# sandbox.toml read_write) fails with PermissionError on first use — silently
# absent from any test that skips that code path. Prefer pointing the library
# inside the project via env var/API (the EDGAR_LOCAL_DATA_DIR pattern, #210)
# over widening three sandbox configs. ~/.cache and ~/.matplotlib are already
# writable in all confining runtimes; audited
# 2026-07-31: wrds (interactive-
# only .pgpass), gdown (~/.cache, allowed), openassetpricing (in-memory
# BytesIO), fredapi/pandas-datareader/requests (no persistent cache).
