- **Save every figure in both formats — vector for the paper, raster for the agents.** Every figure must land as a matched pair with the same basename in the same directory: `foo.pdf` (vector — this is what the paper `\includegraphics`es, and what a journal wants) and `foo.png` (raster, ~150 dpi — this is what a downstream agent can actually *look at*). From matplotlib, that is two `savefig` calls. From a route that emits only PDF (pgfplots/TikZ compiled by LaTeX, an R/Stata export, a solver's own plotting), produce the raster copy yourself — you have Bash: `pdftoppm -png -r 150 -singlefile foo.pdf foo`. This is not redundancy. `paper-writer` has no Bash tool, so a `.pdf`-only figure is readable to it only if `poppler-utils` happens to be installed on the host; without it the figure is invisible, and paper-writer is required to pick the headline figure and write a caption stating what the reader should see — both of which need it to see the plot. A figure it cannot open is a figure it will either omit or caption blind. The raster copy costs one line and removes the dependency entirely.
