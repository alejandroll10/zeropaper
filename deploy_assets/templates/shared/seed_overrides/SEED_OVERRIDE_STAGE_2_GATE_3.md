**Gate 3 KNOWN**: report the concern to `output/seed/novelty_concern_theory.md`. Try **one reformulation** that preserves what the seed pins (different notation, added heterogeneity, different equilibrium selection — anything that might surface a genuinely novel angle without changing what the theory is about). If still KNOWN after one reformulation, stop and write `output/seed/abandon_report.md`. Do not abandon for a different theory. (KNOWN is a directly-prior result; seed — unlike faithful — is permitted to pivot to a different idea when the result already exists in the literature.)

**Gate 3 INCREMENTAL**: do **not** abandon and do **not** hard-stop here. Report the concern to `output/seed/novelty_concern_theory.md` for honest positioning, then **run Stage 3 (implications) and proceed to Stage 4**. Stage 2b (exploration) stays skipped — see the note below — but Stage 3 is not optional: `output/stage3/implications.md` is a hard input to the scorer's Surprise cap/floor rules at Gate 4, to `paper-writer` at Stage 5, and to `puzzle-triager`. The scorer still records its H4 judgment, but under the seeded Gate 4 route that judgment is diagnostic rather than a trigger for branch-manager or abandonment. This mirrors faithful mode's document-and-proceed treatment of the same signal.

> **Known limitation (shared with faithful mode):** this path still skips Stage 2b (exploration), which normally runs after a NOVEL verdict, so the numerical calibration check is foregone before scoring. That is an accepted trade — Stage 2b is the expensive computational pass and the seed's result is pinned, so re-exploring it buys little that Gate 2's math audit has not already established. Stage 3 is **not** part of the trade: it is cheap relative to 2b and its output is consumed by three downstream agents, so it runs.
