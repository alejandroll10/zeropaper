7. **Build the PDF and verify the build.** This is the canonical build procedure — use it for every subsequent rebuild too (polish, referee-response revisions, post-pipeline edits), not just the first draft.
   - **Recipe:** build with `latexmk -pdf main.tex`. `latexmk` sequences `pdflatex` + `bibtex`/`biber` and re-runs to convergence *within a single document* on its own. **Never** hand-roll bare `pdflatex` passes — they resolve `\ref` but skip the bibliography, so every `\cite` renders undefined and the References section ships empty. **When `internet_appendix.tex` was populated and the two documents cross-reference each other** (`\externaldocument` / xr-hyper), `latexmk` cannot resolve the cross-document `\ref`s on its own — each document reads the *other's* `.aux`, which does not exist until that document is compiled. Build to convergence across both: `latexmk -pdf main.tex` (seeds `main.aux`), then `latexmk -pdf internet_appendix.tex` (resolves the IA's cross-references to the main paper from `main.aux` and writes `internet_appendix.aux`), then `latexmk -pdf main.tex` **again** (resolves the main paper's refs into the IA from `internet_appendix.aux`). Skipping the final main pass is the usual cause of `Internet Appendix Section ??` shipping in the main PDF.
   - **Gate.** A build counts as clean only if all six hold (`\ref` resolution, `\cite` resolution, layout, a placeholder-free title page, and legible tables all matter — a clean build on any one of them is not sufficient):
     1. `grep -c 'Citation.*undefined' main.log` returns `0`.
     2. The References/bibliography renders — `main.bbl` is non-empty (`grep -c bibitem main.bbl` > 0) and a References section is present in the PDF.
     3. No bad overflow — LaTeX prints overflows as `Overfull \hbox (NNNpt too wide) ...`; confirm none exceeds 40pt. `awk -F'(' '/Overfull \\hbox/{split($2,a,"pt"); if (a[1]+0>40) print}' main.log` must return nothing (sub-40pt boxes are harmless and ignored).
     4. No unresolved `\ref` — an undefined cross-reference renders as a literal `??` in the PDF (a reader-facing defect a referee reads as sloppiness, and a desk-reject risk) and emits a `LaTeX Warning: Reference '...' undefined` to the log. `grep -c 'Reference.*undefined' main.log` must return `0` — and the same on `internet_appendix.log` when the IA was populated. This is a distinct warning class from check 1's `Citation.*undefined`, so check 1 does not cover it; every `??` in the PDF (including a cross-document `\externaldocument`/xr-hyper ref into the Internet Appendix) corresponds to one of these `Reference ... undefined` lines.
     5. No residual skeleton placeholders — the deployed skeleton ships template tokens that paper-writer must replace (`TITLE PLACEHOLDER`, `ABSTRACT PLACEHOLDER`; the `\author` ships pre-anonymized, not as a placeholder). An unreplaced token renders verbatim onto the title page — a literal `TITLE PLACEHOLDER` as the paper's title is the first thing a desk editor sees, a desk-reject-grade defect no other gate reads back. `pdftotext main.pdf - | grep -c PLACEHOLDER` must return `0` — and the same on `internet_appendix.pdf` when the IA was populated. **Confirm `pdftotext` exists before trusting that `0`:** run `command -v pdftotext >/dev/null || echo GATE-BROKEN` first, and treat `GATE-BROKEN` as a hard build failure, not a pass. This check is the one gate in the six that can *silently invert* — if `pdftotext` is not installed, the shell prints `command not found` to stderr, `grep` reads an empty pipe, and the check prints exactly the `0` that means "clean", so a paper whose title page reads `TITLE PLACEHOLDER` passes. Install `poppler-utils` (macOS: `brew install poppler`) rather than working around it; several other pipeline paths need it as well (the `arpipeline.sty` fingerprint readback, `--mode report` on a PDF-only submission, and the figure producers' `.png` rasterization). Case-sensitive on the literal uppercase token (the skeleton tokens are all-caps; this avoids false-tripping on legitimate lowercase "placeholder" prose), and run against the rendered PDF (not source) so comments and non-`\input`'d scaffolding cannot false-trip it.
     6. No source-detectable illegible table — `arpipeline.sty` makes the compile itself fail with `ARPIPELINE-TABLE-LEGIBILITY-FAIL` when (a) `tabular`/`tabular*`/`longtable` opens below the document class's effective `\scriptsize`, (b) `\resizebox` (plain or starred) or `\scalebox` reduces a `tabular` below that effective floor in either dimension, (c) command-form `\adjustbox` makes an unambiguous two-axis reduction below the floor, (d) a table is wrapped in nested transforms or the opaque `adjustbox` environment, (e) an `array` used inside a semantic `table`/`table*` float violates the same rules, or (f) a semantic table float consists of a pre-rendered image instead of native table source. Pure `adjustbox` rotation and transformed equation arrays are not source violations; the rendered audit in step 8 decides ambiguous one-axis/compound transforms and custom table-like exhibits. `grep -c 'ARPIPELINE-TABLE-LEGIBILITY-FAIL' main.log` must return `0` — and the same on `internet_appendix.log` when the IA was populated. Exactly `\scriptsize` is allowed. A narrow table scaled up is allowed. A scaled figure outside a semantic table float is not table content and is allowed. Do not weaken the package error into a warning: a nonzero `latexmk` exit on this marker is the gate working.
   - If any check fails, fix it (run the full `latexmk` recipe; correct cite keys or `references.bib`; fix the offending table/float; for an unresolved cross-document IA `\ref`, run the full cross-document build sequence from the recipe above — `main.tex` → `internet_appendix.tex` → `main.tex` — so each document's `.aux` exists before the document that references it is finalized; for a residual placeholder, fill the token with real content and rebuild; for an `ARPIPELINE-TABLE-LEGIBILITY-FAIL`, re-typeset natively and legibly per the wide-table guidance — `\footnotesize`/`\scriptsize` with wrappable columns, a `\sidewaystable`/landscape, or relegate the full table to the Internet Appendix — rather than bypassing `arpipeline.sty`) and rebuild before committing. Do not report the build as clean on the strength of one check alone.
   - **Rebind after build repairs.** Once all six checks are clean, run `results_pipeline.py verify-paper --receipt process_log/paper_evidence.receipt.json --rerender`. If any build-driven repair changed LaTeX, bibliography, captions/notes, references, placeholders, or table/float source, that command must be stale; run `docs/results_evidence.md` with checkpoint `stage5-build-rN` and require a new bound PASS before launching `table-auditor`. A clean table-auditor verdict cannot certify an unrelated build repair.
8. **Rendered-table gate.** After all six build checks pass, launch `table-auditor` on `paper/main.pdf` + its LaTeX source and, when populated, `paper/internet_appendix.pdf` + its source. Instruct it to write `output/stage5/table_legibility.md`. This audit is mandatory even when the source gate found nothing: it catches custom alignments, image tables misclassified as figures, raster text with no PDF glyphs, clipping/overprinting, and other source-level escape paths. Verify the report exists, is non-empty, and contains exactly one first-line routing field `VERDICT: PASS`, `VERDICT: REVISE`, or `VERDICT: GATE-BROKEN`.
   - **PASS:** if any table-legibility repair changed the paper since the current paper-evidence receipt was bound, run `docs/results_evidence.md` with checkpoint `stage5-tables-rN`; then reset `loops.table_legibility.round` to `0` and proceed.
   - **REVISE:** increment `loops.table_legibility.round`, re-launch `paper-writer` with the complete findings, then return to step 7 for a fresh build and re-audit the new PDF. This retry is the documented retry-regenerates-artifact exception: the paper-writer layout rewrite does **not** reset the counter. If `loops.table_legibility.round >= loops.table_legibility.cap` and the new render still receives REVISE, halt for operator routing; do not ship an unreadable table or silently downgrade the finding.
   - **GATE-BROKEN:** halt and surface the missing/unreadable rendering dependency (normally `pdftoppm` from `poppler-utils`). Do not increment the legibility loop and do not treat unread input as PASS.
   - A missing/empty report or an undeclared verdict is the same as `GATE-BROKEN`: re-fire `table-auditor` once for write integrity, then halt if it still fails. Do not substitute the orchestrator's own visual judgment for the independent audit.
9. Commit: `pipeline: stage 5 — paper draft written`
